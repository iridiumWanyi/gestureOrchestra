Put one audio recording per note here, named exactly by note:

  G3  A3  B3  C4  D4  E4  F4  G4  A4  B4  C5

Accepted extensions: .wav .mp3 .flac .ogg .aiff
Examples:  G3.wav   C4.mp3   A4.flac

Tips:
- Use a sustained, steady tone of the instrument you want (the app loops it
  while you hold the note), so a seamlessly-loopable sustain sounds best.
- Any sample rate is fine; it is resampled to 44100 Hz on load.
- Any note without a file falls back to a soft synth tone, so the app always
  runs. Add files gradually and they override the fallback.
